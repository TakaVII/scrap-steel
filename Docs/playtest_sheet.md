## 2. Accessibility & Assist Options Verification
Before starting a run, test toggles in **Settings Menu**:
- [ ] **Colorblind Mode**: Palette switches to Blue (#2b83ba), Vermilion (#d7191c), and Amber (#fdae61) with [✓] and [✗] shape redundancy.
- [ ] **Input Mode (Hold vs Toggle)**: Calibrator minigame operates correctly in both modes.
- [ ] **Slow Mode**: Minigame speeds scale to 0.75x; success windows increase by 25%.
- [ ] **Minigame Skip**: Skip button auto-resolves parts with fixed 0.80 quality.
- [ ] **Arabic RTL**: TextServer Advanced renders cursive ligatures; UI containers mirror right-to-left.
