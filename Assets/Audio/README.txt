SCRAP & STEEL — ASSETS/AUDIO DIRECTORY SPECIFICATION
=====================================================

All audio must be OGG Vorbis, 44.1 kHz, mono where possible, <= 96 kbps.
Single-threaded web builds require minimal memory overhead.

1. Music Loops (150-160 BPM Techno / Cyberpunk, composed in BeepBox):
   - music_workshop_loop.ogg (calm workshop vibe, low percussion)
   - music_minigame_loop.ogg (high intensity, matched key/tempo for seamless crossfade)
   - music_night_summary.ogg (short 4-bar recap chime)
   - music_victory_sting.ogg (championship / triumph sting)
   - music_seizure_sting.ogg (syndicate repossession game-over sting)

2. Sound Effects (12 core SFX, mono OGG or WAV <= 22kHz):
   - sfx_strike_hit.ogg (sweet spot hit in The Forge)
   - sfx_strike_miss.ogg (missed strike)
   - sfx_calibrator_tick.ogg (RPM zone retention tick)
   - sfx_assembler_step.ogg (node connection click)
   - sfx_assembler_hazard.ogg (short-circuit zap)
   - sfx_credit_coin.ogg (money earned / payout)
   - sfx_ui_click.ogg (menu navigation)
   - sfx_warning.ogg (rent or strike penalty alert)
   - sfx_stamp.ogg (contract signature / approval)
   - sfx_upgrade_buy.ogg (R&D unlocked)
   - sfx_installment_due.ogg (syndicate notice sound)
   - sfx_overtime_activate.ogg (night shift power buzz)
